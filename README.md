🎯 Project Purpose

RF-Global helps Israeli investors discover high-yield real-estate opportunities in Cincinnati, Ohio.
This platform provides:
	•	Clear investment modules
	•	Property presentation system
	•	High-trust brand design
	•	Blog for market insights
	•	ROI calculator and visual analytics
	•	Contact & lead-capture workflows
	•	SEO-optimized content structure

⸻

🛠️ Tech Stack

Frontend
	•	HTML5
	•	CSS3 + TailwindCSS
	•	JavaScript (Vanilla)
	•	Responsive Modern UI
	•	Google Fonts (Rubik, Heebo)

Backend / Storage
	•	Hostinger Web Hosting
	•	SSL Certificates (Hostinger HTTPS)

Analytics & Tracking
	•	Google Analytics 4 (GA4)
	•	Google Search Console (GSC)
	•	Custom SEO Metadata + OG Tags

Email & Automation
	•	EmailJS (Contact + Newsletter)
	•	Real-time form submission
	•	Custom templates for lead tracking

Version Control
	•	Git & GitHub

Build Approach
	•	Static HTML site
	•	Organized folder structure
	•	SEO-optimized URLs
	•	Fully manual clean deployment

⚙️ Main Features

🔹 Modern Real-Estate Landing Page

Clear value proposition, investor-friendly visuals, and high-trust design.

🔹 Modular Investment System

Each investment module includes:
	•	Description
	•	Benefits
	•	CTA

🔹 Properties Listing

Grid layout + filters
Designed for reading investments quickly.

🔹 Blog System

SEO-ready blog posts with:
	•	OG images
	•	Schema markup
	•	Attractive layouts
	•	Smooth typography

🔹 ROI Calculator (Chart.js)

Interactive:
	•	Donut chart
	•	Growth-over-time line chart
	•	Multi-currency support (ILS / USD / EUR)

🔹 Dark, Elegant Financial UI

Tailored to the RF-Global identity:
	•	Midnight dark
	•	Gold accents
	•	Deep green trust colors

🔹 Fully Responsive

Built for:
	•	Mobile
	•	Tablet
	•	Desktop
	•	Ultra-wide screens

🔹 Fast Performance

Optimized:
	•	Images (AVIF + WEBP)
	•	Lazy loading
	•	Tailwind JIT
	•	Clean JS without libraries
